# TypeScript Train

スマホ／PCブラウザで使える、無料・オフライン対応のTypeScript学習アプリです。外部サービスや課金、依存パッケージは使いません。

## 使い方

このフォルダで次を実行し、ブラウザで `http://localhost:4173` を開きます。

```powershell
node server.js
```

最初の表示時に教材が端末に保存されます。ブラウザのメニューから「ホーム画面に追加」または「インストール」を選ぶと、アプリのように起動できます。出発前に一度開いておけば、以後は通信を切っても使えます。

## 収録内容

- 型注釈と推論、関数、オブジェクト、ユニオン型、ジェネリクス、非同期処理
- 選択式とコード穴埋め式の確認問題
- ブラウザ内への進捗保存
- TypeScript → ブラウザ API → Next.js → WebAssembly の学習ロードマップ

`app.js` は実行用ファイルです。学習目的でアプリ自体をTypeScript化する場合は、同じ構造で `app.ts` に移し、TypeScriptコンパイラでJavaScriptへ変換してください。
